## 🕵️‍♂️ Overview

**Detective-L** is an advanced interactive cyber-noir criminal investigation system designed to crack complex unsolved cold cases and locked-room murder mysteries. Featuring real-time suspect cross-examination powered by Groq's high-speed LLaMA-3.3 model, an interactive red-string pinboard, an OSINT cyber intelligence lab, and a grand jury verdict chamber.

---

## ✨ Key Features

### 1. 👥 5-Suspect AI Interrogation Chamber
- **Deep Persona Roleplay**: 5 distinct suspects per case with concealed motives, complex alibis, psychological vulnerabilities, and voice styles.
- **Biometric Lie Detector HUD**: Real-time cardiac pulse telemetry (BPM), psychological stress gauge, micro-expression observation, and telltale physical signs.
- **Evidence Confrontation**: Challenge suspects with discovered physical and forensic evidence to shatter fabricated alibis.
- **Master Detective "L" Copilot**: Instant deductive advice, timeline contradiction spotting, and strategic inquiry recommendations.

### 2. 🧶 Interactive "Connect-the-Dots" Evidence Pinboard
- **Dynamic Red String Linking**: Draw realistic red yarn connections between suspects, clues, autopsy records, and timeline leads.
- **Customizable Relationship Tags**: Annotate links (*"Contradicts Alibi"*, *"Motive Link"*, *"DNA Match"*, *"Financial Connection"*).
- **Auto-Deduction Engine**: Detects matching hypotheses and unlocks breakthrough investigative deductions.

### 3. 🌐 OSINT & Web Intelligence Matrix
- **DarkNet & Leak Searcher**: Probe compromised databases, encrypted forum messages, and cryptocurrency transfers.
- **Cell Tower Geo-Tracker**: Reconstruct movement timelines using cell tower CDR logs and access control pings.
- **Digital Forensics Suite**: Decrypt Signal phone dumps, extract EXIF metadata, and examine IoT sensor telemetry.

### 4. 📸 Panoramic Crime Scene Explorer
- **Interactive Hotspot Sweeps**: Examine the crime scene with optical loupes, UV Luminol spray (revealing latent chemical residues), and latent fingerprint dusting.
- **Auto-Filing**: Discovered evidence is automatically cataloged in the Case Dossier and pinned to the corkboard.

### 5. ⚖️ Accusation & Grand Jury Chamber
- **Indictment Formulation**: Designate the true culprit, murder weapon, motive, and fatal contradiction.
- **Verdict Cutscene & Ranking**: Real-time jury evaluation, villain confessions, and detective score rating (Rookie Sleuth $\rightarrow$ Master Detective L).

### 6. ✨ Groq AI Custom Case Generator
- Procedurally generate infinite cold case scenarios with 5 custom suspects, crime scenes, and logic-tight clues with a single prompt.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18 or higher)
- npm (v9 or higher)
- Groq API Key ([Get one free at Groq Cloud](https://console.groq.com))

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/rakeshsoniiii/Detective-L.git
cd Detective-L

# 2. Install dependencies
npm install

# 3. Configure environment
# Add your Groq API key to .env:
# VITE_GROQ_API_KEY=gsk_your_key_here

# 4. Start local development server
npm run dev
```

Visit `http://localhost:3000` to launch Detective-L!
